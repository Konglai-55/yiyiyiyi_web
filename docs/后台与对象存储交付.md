# 网站管理与图片存储

## 本地使用

- 在 site 目录运行 `npm run dev`，访问输出的地址加 `/admin`。
- 初始密码在 `.private/后台登录.txt`，不要提交到代码仓库。
- 新闻支持新建、编辑、封面上传、草稿、发布、下架、删除和排版预览。
- 现有五篇文章在首次登录后台读取列表时导入数据库；以后不覆盖编辑内容。
- 发布为未来日期的文章到当日北京时间开始显示。
- 删除不可撤销；临时隐藏建议使用下架。

## 图片

- Bucket：`yiyiyiyi`；外链：`https://yiyiyiyi.cn-nb1.rains3.com`。
- 42 个网站公开图片资源已迁移，内容校验通过。对应关系在 `lib/asset-manifest.json`。
- 仅 `website/` 前缀允许匿名读取，不能匿名上传、删除或列举桶。
- 图片地址带内容哈希且缓存一年；更换图片应使用新地址。
- 原图仍保留在 public 中用于恢复，但构建不再复制图片目录。
- 新闻封面经鉴权服务上传到 `website/news/`；访客直接从对象存储加载。
- 目前使用存储商提供的域名，没有配置自有域名 CNAME。配置自有域名需要域名及 DNS 控制权。

## 统计口径

- PV、访问会话、今日浏览量、页面排行、每日趋势、设备和来源域名。
- 保存 90 天，不保存原始 IP；尊重 DNT/GPC，排除后台与常见爬虫。
- 会话为标签页随机标识经服务端 HMAC 后存储，不等于准确人数。
- 统计非计费依据，脚本拦截与伪造请求均可能影响准确性。

## 部署前必须完成

1. 配置真实持久化 D1 数据库 `DB`，应用 `drizzle/0000_loud_medusa.sql`。本地 `.wrangler/state` 不自动上传到线上。
2. 将 `.dev.vars` 的 S3 和管理员 secrets 安全配置到运行环境，不能放在客户端环境变量中。
3. HTTPS 部署后登录 Cookie 自动使用 Secure；密码错误限制为每来源 15 分钟 5 次，登录有效期 8 小时。
4. 初始化后备份 D1；密码遗失时在服务端重新设置密码哈希并清除 admin_sessions。
5. 当前 Sites 项目标识查询返回 project not found，因此没有部署线上版本。不要直接发布未配置 DB/secrets 的构建。

## 验收

`node scripts/verify-admin.mjs` 检查登录、未授权拒绝、CSRF、草稿不可见、发布、下架、并发修改保护、无效图片/URL、删除和退出登录。只在本地运行。
